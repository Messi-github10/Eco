## 2. 特征工程铁律

| 规则 | 原因 |
|---|---|
| **只用 t 日及之前数据算因子** | t+1 建仓，绝不用未来数据 |
| 季报数据按 `publish_date` 对齐 | 按报告期对齐 = 信息泄漏 |
| 因子做**横截面标准化**（z-score / rank） | 消除量纲，抗极值 |
| 极值处理：winsorize 1%/99% | 防单点主导 |
| 缺失值：前向填充，首日缺失则剔除该标的 | |
| **不把原始价格喂模型** | 非平稳，模型学不到东西 |
| 因子相关性 > 0.9 择一保留 | 防共线性 |

## 4. 因子有效性检验（做模型前必做）

| 指标 | 含义 | 门槛 |
|---|---|---|
| IC | 因子值与下期收益的截面相关 | \|IC\| 均值 > 0.03 |
| ICIR | IC 均值 / IC 标准差 | > 0.3 |
| IC 胜率 | IC 同号占比 | > 55% |
| 分组单调性 | 按因子分 5 组，收益是否单调 | 基本单调 |
| 换手率 | 因子自身稳定性 | 越低越好 |

**跑完这步再决定上不上模型。** 因子没 IC，模型再好也是噪音。

### 4.1 统计显著性检验（不能只看点估计）

20~40 只标的的截面天然窄，`|IC|均值 > 0.03` 这类点估计**单独看很容易被噪音凑出来**——必须同时报告显著性，否则"因子有效"的结论不可信：

| 检验 | 做法 | 门槛 |
|---|---|---|
| IC 均值的 t 统计量 | `t = IC均值 / (IC标准差 / √T)`，T 为时序样本数（月频约60~120期） | \|t\| > 2（对应 p < 0.05） |
| p 值 | 双侧检验，H0: IC均值=0 | p < 0.05 |
| 最小样本量 | 月频调仓下，回测覆盖期 < 3 年（约36期）时，IC统计量的置信区间会很宽，**结论仅作参考，不下强结论** | 建议回测覆盖 ≥ 5 年（60期以上）才正式采信 IC 检验结果 |

### 4.2 多重检验校正（防止"试出来的因子"）

02-factors.md §1 列了 8 类因子、合计 40+ 个具体因子。**同时检验这么多因子，即使全部是噪音，也会有若干个"偶然"通过 `|IC|>0.03` 且 `p<0.05` 的门槛**——这是多重检验问题，必须校正，否则相当于"试了100个因子挑最好的"（05-risks.md 已列为方法论风险，这里给出具体做法）：

| 方法 | 做法 |
|---|---|
| Bonferroni 校正（简单保守） | 若同时检验 k 个因子，显著性阈值改为 `p < 0.05 / k`（如检验40个因子，阈值收紧到 p < 0.00125） |
| FDR 校正（推荐，功效更高） | 用 Benjamini-Hochberg 方法控制假发现率，允许控制在"通过检验的因子中最多 5% 是假阳性"，比 Bonferroni 少误杀真实有效因子 |
| 样本外复验（最终确认，必做） | 校正后仍显著的因子，**必须**在样本外（未参与筛选的时间段）重新算一次 IC，样本外仍显著才最终采纳入模型特征——样本内显著、样本外不显著是过拟合的典型信号 |

**执行顺序**：先算全部因子的 IC（样本内）→ 做 FDR 校正筛出候选 → 候选因子在样本外复验 → 通过两轮才进 L3 模型特征列表。任何单轮通过就直接使用都不够审慎。
