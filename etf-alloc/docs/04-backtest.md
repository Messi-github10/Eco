# L4 回测引擎方案

## 1. 这是整个项目工作量最大的部分

模型可以简单，回测不能。**回测不真实的策略，实盘一定亏。**

## 2. Walk-forward 框架（强制）

```
|<-------- 训练 750 日 -------->|<-- 验证 120 日 -->|<-- 测试 60 日 -->|
                                                    ↑ 此处产生权重
                                                    ↓ 前移 60 日，重复
```

| 规则 | 说明 |
|---|---|
| 禁止随机切分 | 时序数据随机切分 = 未来函数 |
| 禁止用测试集调参 | 测试集只看一次 |
| 滚动重训 | 每期重新训练模型，不能用同一模型穿越 |
| 预热期 | 前 250 日只算因子，不产生权重 |
| 样本外 | 最终报告只报测试期结果 |

## 3. 成本模型（必须扣，不扣必假）

| 成本项 | 取值 |
|---|---|
| 佣金 | 万 0.5 ~ 万 2.5（按券商） |
| 冲击成本 | `α · √(order_amt / daily_amt)`，α ≈ 0.1 |
| 买卖价差 | ETF 约 0.1%~0.2%（宽基）/ 0.3%~0.5%（冷门） |
| 折溢价成本 | 跨境 ETF 按实际折溢价买入 |
| 管理费 | 按年化扣，ETF 0.15%~0.5%，QDII 0.5%~1.2% |
| 托管费 | 按年化扣，0.05%~0.25% |
| 印花税 | ETF 免；LOF 按股票规则 |
| QDII 确认时滞 | **T+2 生效**，资金占用 |

**扣费后回测净值与不扣费对比，差距通常 > 30%。** 这个对比必须做，贴在报告里。

### 3.1 个人账户成本校准（不要直接套用上表区间，区间跨度太大没法用）

上表的取值是覆盖各类资金规模的**通用区间**，个人小资金账户直接拿区间中值算回测，容易和真实成本偏差很大。校准步骤：

1. **佣金**：登录自己的证券账户，查最近 3~5 笔 ETF 成交的实际佣金（含最低5元/笔的隐性下限，很多券商即使按万分之几算出来不到5元也按5元收），用这个真实值，不用文档区间
2. **买卖价差**：不要用"宽基0.1%~0.2%"的估计，直接看自己实际下单时的盘口——用（卖一价-买一价）/中间价，对你标的池里的每只ETF在几个不同时间点抓一下盘口价差，取平均，这个才是你会真实承受的价差
3. **冲击成本**：个人账户单笔金额相对ETF日成交额（多数在5000万以上）通常占比 < 0.5%，`α·√(order_amt/daily_amt)` 算出来的数值会趋近于0——**建议直接设为0或忽略**，不要因为公式存在就照抄机构的 α≈0.1，那是给大资金校准的参数，对小资金会系统性高估这一项成本（虚增回测的悲观程度，反而误导决策）
4. **成本重心结论**：个人账户的真实成本大头是「佣金固定下限 + 买卖价差」，不是冲击成本——这与机构资金正好相反（机构最怕冲击成本），04-backtest.md 后续所有涉及成本敏感性测试（§7）时，应针对"佣金+价差"这两项做敏感性分析，而不是重点测试 α 参数

## 4. 可执行性约束（写在回测里，不是事后过滤）

| 约束 | 处理 |
|---|---|
| 涨跌停 | 涨停不买入，跌停不卖出 |
| 停牌 | 当日不可交易，权重顺延 |
| 流动性 | 单标的建仓额 ≤ 当日成交额 × 1% |
| 最小交易单位 | 100 份（1 手）取整 |
| 现金 | 未满仓部分计活期利息（年化 ~1.5%） |
| QDII 限购 | 限购期不可建仓 |
| T+1 | ETF 当日买不可当日卖（场内 T+0 的跨境除外，需甄别） |

## 5. 性能指标（全部输出）

| 类别 | 指标 |
|---|---|
| 收益 | 累计收益、年化收益、月度胜率 |
| 风险 | 年化波动、最大回撤、回撤持续期、VaR 95%、CVaR 95% |
| 风险调整 | Sharpe、Sortino、Calmar、Omega |
| 相对 | 相对基准超额、信息比率 IR、跟踪误差、Alpha、Beta |
| 交易 | 年化换手率、交易次数、平均持仓周期、总成本 |
| 稳定性 | 滚动 12 月 Sharpe 的均值与标准差 |
| 尾部 | 最差 5% 月份的平均收益 |

**必报**：`Sharpe`、`MaxDD`、`Calmar`、`换手率`、`扣费前后对比`。

## 6. 归因分析

### Brinson 归因
```
超额收益 = 配置效应 + 选择效应 + 交互效应
```
（ETF 场景"选择效应"= 同一类资产内选不同 ETF 的贡献）

### 因子归因
组合暴露 vs 基准暴露，看收益来自哪些因子：
- 是动量贡献？还是纯 Beta？
- 剥离 Beta 后还剩多少 Alpha

### 权重归因
| 观察 | 含义 |
|---|---|
| 权重集中在少数标的 | 优化器太激进，λ 需调大 |
| 权重频繁大幅切换 | 信号噪音大，需加平滑/漂移带 |
| 某标的长期满配 | 因子失效或数据错误 |

## 7. 稳健性测试（加分项，但很能说明问题）

| 测试 | 做法 | 通过标准 |
|---|---|---|
| 参数敏感性 | 调 K、λ、τ、窗口 | 邻域内不崩 |
| 起始日敏感性 | 换 5 个不同起点 | 结果方向一致 |
| 成本敏感性 | 成本 ×2（个人账户重点测「佣金+价差」×2，冲击成本项可不测，见 §3.1） | 仍为正超额 |
| 标的池敏感性 | 换掉 20% 标的 | 结果不崩 |
| 蒙特卡洛 | 打乱标的顺序 | 与基准统计一致 |
| 子期分析 | 分牛市/熊市/震荡 | 熊市不能爆 |

## 8. 反过拟合检查清单

- [ ] 参数个数 << 样本数
- [ ] 测试期从未参与任何决策
- [ ] 扣费后仍正超额
- [ ] 基线2 已被打败（否则不承认 ML 的价值）
- [ ] 滚动 Sharpe 不是靠某一段暴利撑起来的
- [ ] 换手率 < 500%/年（月频合理范围）
- [ ] 从因子 IC 到最终收益的链条可解释

## 9. 输出物

```
reports/backtest_YYYYMMDD/
  nav_curve.csv           净值曲线
  weights_history.csv     权重历史
  metrics.json            全部指标
  attribution.csv         归因
  robustness.json         稳健性测试
  report.html             汇总报告（可交互）
```

## 10. 回测与实盘的差距（提前认知）

| 差距来源 | 影响 |
|---|---|
| 滑点假设偏乐观 | 实盘收益低于回测 |
| 流动性瞬时变化 | 大额建仓困难 |
| 折溢价波动 | 跨境 ETF 尤其明显 |
| 模型随时间失效 | 需要持续监控重训 |
| 幸存者偏差 | 标的池若只含现存 ETF，收益虚高 |

**建议**：实盘先小资金验证 3 个月，对比回测，实测偏差比才能用于后续校正。
