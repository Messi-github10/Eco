## 核心结论（先读这段）

**原始思路的 3 处修正**：

1. **第 3 步 "预测持仓权重"** → 拆成「预期收益/排序预测」+「权重优化」两段。
   端到端预测权重是 *error maximizer*，μ 的微小误差会被放大成极端权重。

2. **第 4 步 "与实际收盘结果对比"** → 权重没有"实际收盘"可对照。
   正确做法是 **walk-forward 回测 + 归因**，统一到收益口径闭环。

3. **QDII 一期不做** → 净值滞后（T+1~T+2）+ 时区差 + 限购 + 高溢价，
   难度比 A 股 ETF 高一个量级。先拿 A 股 ETF 打通闭环。

**可行性**：数据层 ★★★★★ / 指标看板 ★★★★★ / 组合优化 ★★★★★ /
**ML 超越基线 ★★☆☆☆**。项目真正确定能交付的是"无泄漏的数据与回测管道 +
经检验的因子体系 + 纪律化决策流程 + 风险降级机制"，ML 超额是 bonus。
